# NBA 2K26 Elite Shooting & Dribbling Guide

## SHOOTING — Mastering Every Shot Type

### Core Shooting Methods

| Shot Type | Input (Shot Stick) | When to Use |
|-----------|-------------------|-------------|
| **Jump Shot (Timed)** | Hold RS down, release at top of animation | Standard catch-and-shoot or off-dribble |
| **Jump Shot (Rhythm)** | Flick RS down then up in sync with jump | More responsive, simulates real shooting motion |
| **Go-To Shot** | RS straight up, release at top | Get to your spot in the clutch |
| **Pull-Up Jump Shot** | Hold RS down, release up (with momentum) | Off the dribble or on the move |
| **Quick Shot** | Hold LT/L2 while receiving pass, then shoot | Beat close-outs off the catch |

### Finishing at the Rim

| Shot Type | Input | When to Use |
|-----------|-------|-------------|
| **Normal Layup** | RS up while driving | Standard finish |
| **Reverse Layup** | RS right while driving baseline | Avoid blocks along baseline |
| **Eurostep Layup** | RS down-left (ball in right hand) | Step through defenders in paint |
| **Hop Step Layup** | Hold RT + RS down-left/right | Bounce past defenders athletically |
| **Floater/Runner** | Hold RS down while in the paint | Loft over big men |
| **Two-Hand Dunk** | Hold RT + RS up (close range) | Power finish |
| **Skill Dunk** | Hold RT + RS down while driving | Flashy dunk |
| **Step Through** | Tap shoot to pump fake → RS any direction | Standstill near basket |

### Post Moves

| Move | Input | Notes |
|------|-------|-------|
| **Post Fadeaway** | Hold L2/LT (post up), LS away from rim, double-tap Square/X (hold 2nd tap) | Great mid-range weapon |
| **Post Shimmy Hook** | Hold L2/LT, LS toward hoop (left/right), tap Square/X | Close-range finish |
| **Drop Step** | Hold L2/LT, LS toward basket, release then Square/X | Attack the rim from post |

### Green Window / Settings for Elite Shooting

- **Turn shot meter OFF** (Customize HUD → Shot Meter → No) — gives a hidden green window boost
- **Shot Timing: Visual Cue** set to "Push" or "Release" (personal preference)
- **Shot Feedback: All Shots** — to track your timing
- **Target attributes:** 99 Three-Point + 90+ Agility for max green window
- **Pro tip:** Start with meter ON until you green ~80% in practice, then turn it OFF and learn by animation feel
- **Rhythm shooting tempo:** Aim for 35-60ms between down-up flicks for optimal rhythm

### Green Window Size by Animation Type

| Animation Type | Green Window | Best For |
|---------------|-------------|----------|
| Quick Release | Smaller | High-skill players with excellent timing |
| Standard | Medium | Balanced shooters with good consistency |
| Slower Release | Larger | Learning the system or lower 3PT rating |
| Custom (Jump Shot Creator) | Variable | Competitive players optimizing for playstyle |

### Key Shooting Badges (Season 5)

- **Limitless Range** — shoot deep threes
- **Catch & Shoot** — boost off-ball shooting
- **Green Machine** — wider green window on hot streaks
- **Deadeye** — hit contested shots

### Speed Boost Moves (The Meta Combos)

#### 1. Zach LaVine Speed Boost (fundamental blow-by)
- Hold RT the entire time
- Ball in right hand → flick RS diagonally up-left
- Immediately hold LS in the direction you want to explode

#### 2. D-Book Snatchback (ankle breaker)
- While running forward, hold RT + LS up
- Flick RS straight down
- Explode out with LS after the snatchback animation

#### 3. D-Book Quick Stop (instant pull-up)
- After a speed boost, keep holding RT
- While running to the side, flick RS down
- Immediately shoot (Square/X) to cancel into a quick-stop jumper

#### 4. Behind the Back (Scottie Pippen)
- Hold RT while running
- Ball in left hand → flick RS diagonally down-right (or opposite)
- Be careful in traffic — easy turnover if you go into a defender

#### 5. Momentum Crossover (chain/setup move)
- Ball in left hand → flick RS straight up
- Immediately hold RT + LS in direction you want to go

#### 6. Left Stick Cancel (advanced/glitchy)
- Perform an escape move (hold RT + RS opposite direction)
- Immediately release RT
- Immediately flick LS in the same direction as the escape
- Spam back and forth for unpredictable movement

### Combo Chains (Beginner → Advanced)

|-------|----------|------------|

| Hesitation → Crossover | RS right (release) → RS up | Intermediate |
| Pro Hop → Crossover | RS down → up → direction change | Intermediate |
| Behind-Back → Crossover | RS down-left → quick direction flick | Advanced |
| Momentum Cross → BTB → Quick Stop | RS up → RS down-left → RS down + shoot | Advanced |

## Practice Plan

1. **MyCOURT** — practice each move in isolation until the input is muscle memory
2. **Chain 2 moves together** — size-up → crossover, hesitation → drive
3. **Add shooting off dribble** — every combo should end in a shot attempt
4. **Graduate to 1v1** — test moves against AI defenders
5. **Go online** — adapt combos based on how real players defend you

---

*Key takeaway: dribbling isn't about flashy moves — it's about creating an open shot. Every combo should serve that goal.*
