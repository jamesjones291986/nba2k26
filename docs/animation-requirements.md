## Hidden Animation Thresholds ("Rule of Fives")

Beyond signature animations, your attributes unlock hidden default movement animations at specific thresholds:

| Attribute | Threshold | What Unlocks |
|-----------|-----------|--------------|
| Ball Handle | 60 | Faster momentum crossover |
| Ball Handle | 85+ | Fastest "dribble god" momentum crossover |
| Standing Dunk | 40+ | Basic standing dunk animations |
| Steal | 45 | Faster pluck animation |
| Steal | 51+ | Fastest on-ball rip |
| Rebound | 79+ | Aggressive one-handed snag animations |

**Rule of Fives:** Thresholds land on multiples of 5. If an attribute is at 84, push to 85. That one point could unlock a game-changing animation.
