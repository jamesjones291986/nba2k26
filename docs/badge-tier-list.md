## Badge Tier Classification (Tier 1 / Tier 2 / Shooting)

Badges are classified into **Tier 1**, **Tier 2**, or **Shooting** categories. This determines which badge boost pool they draw from. Classification changes by height.

> Source: nba2klab.com/badge-tier-unlocks

### Shooting Badges (all heights)
These always use the Shooting boost pool regardless of height:
- Set Shot Specialist (Tier 1 at all heights)
- Deadeye (Tier 1 at all heights)
- Limitless Range (Tier 1 up to 7'0, Tier 2 at 7'1+)
- Shifty Shooter (Tier 1 up to 6'9, Tier 2 at 6'10–6'11)
- Mini Marksman (Tier 1, ≤ 6'3 only)

## Overall Meta Tier List

### S Tier (Must-Have on Any Build That Can Get Them)
| Badge | Why |
|-------|-----|
| Set Shot Specialist | Biggest green window boost; works on catch-and-shoot AND off-dribble standstills |
| Lightning Launch | Explosive first step; #1 playmaking badge in the game |
| Posterizer | Contact dunk success; dominant at Gold+ |
| Paint Patroller | Best rim protection badge for bigs |
| Challenger | Best perimeter contest badge |
| Interceptor | Lane steals are free points in transition |
| Pogo Stick | Faster second jump; essential for bigs on blocks/rebounds |

### A Tier (Highly Recommended)
| Badge | Why |
|-------|-----|
| Limitless Range | Extends 3PT range to logo; warps defense |
| Deadeye | Reduces contest penalty (less impactful than 2K25 due to weak contests) |
| Handles For Days | Stamina on dribble combos; core for ball handlers |
| Rise Up | Standing dunks trigger more often; great for centers |
| Immovable Enforcer | Stops blow-bys with strength |
| On-Ball Menace | Drains ball handler stamina; elite for guards |
| Pick Dodger | Navigate screens; Legend tier recommended |
| Float Game | Underrated; floaters are high-percentage in traffic |
| Rebound Chaser | Expands rebounding range |

### B Tier (Situational / Build-Dependent)
| Badge | Why |
|-------|-----|
| Shifty Shooter | Good for fadeaway/off-dribble shot creators |
| Physical Finisher | Contact finishes at rim |
| Boxout Beast | Rebounding position; secondary to Rebound Chaser |
| Break Starter | Outlet passes after boards |
| Brick Wall | Stronger screens; PF/C only |
| Post Lockdown | Shuts down post scorers |
| Layup Mixmaster | Acrobatic layups; guards only |
| Paint Prodigy | Inside scoring for centers |

### Low Tier (Skip or Low Priority)
| Badge | Why |
|-------|-----|
| Glove | Steal animations nerfed; not worth the attribute investment |
| Unpluckable | Steals are already hard to get in 2K26; less necessary |
| Dimer | Shooting is easy enough that pass boost is marginal |
| Ankle Assassin | Flashy but RNG-dependent; unreliable |
| Hook Specialist | Too niche; only for dedicated post builds |
| Slippery Off-Ball | Low impact compared to other options |
| Post-Up Poet | Post fakes rarely meta-relevant |

## Key Takeaways

1. **Set Shot Specialist is king** — every build that shoots should have it at Gold minimum
2. **Lightning Launch is the #1 playmaking badge** — if your height allows it, get it
3. **Steal badges (Glove) are a trap** — steals are nerfed, the attribute investment isn't worth it
4. **Pogo Stick is non-negotiable for bigs** — second-jump blocks win games
5. **Pick Dodger at Legend** is the difference between getting cooked on screens and staying attached
6. **Dimer and Unpluckable are overrated** — shooting is easy enough and steals are rare enough that these provide marginal value
7. **Posterizer with 93 Driving Dunk** is the finishing sweet spot for guards/wings
