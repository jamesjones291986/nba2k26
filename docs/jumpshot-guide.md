## Green Window Mechanics

- Green window width: ~50-60ms for most jumpshots
- All shots fall between 550ms-750ms total release time
- Shot meter OFF grants a green window boost
- Higher 3PT/Mid-Range ratings = larger green windows
- Set Shot Specialist badge dramatically increases green window

### Rhythm-Specific
- 2D system: Push Timing (540-570ms) × Tempo (35-60ms)
- Post-Patch 2.0: 14% make rate decrease, tighter windows
- Mid-range rhythm still very effective; 3PT tempo fades hit hardest
- Dribble pull-up for rhythm: **Nikola Jokic** (best) or Pro 2

## Pro Tips

1. **Shot Meter OFF** = confirmed green window boost
2. **No-Dip Technique**: Hold LT before catching to remove dip animation (faster release)
3. **Adrenaline**: Don't shoot with 1 bar — 2-3 bars = better green window
4. **Beluba** is the dominant upper release — maximizes green window in nearly every combo
5. **Kavi's testing**: All 367 bases tested for 6'5-6'9 on HoF, 90 3PT, silver badges, pure Beluba. Top 3: Quentin Grimes, Ray Allen, Carmelo Anthony
6. **Post-patch rhythm**: Still viable but requires tighter timing. Button shooting was unaffected by Patch 2.0
